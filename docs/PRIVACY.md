# Paperpane（纸间）隐私政策

更新于 2026 年 11 月 10 日。

Paperpane 是用于阅读、翻译、批注和整理学术论文的浏览器扩展。扩展可以离线阅读、批注和记笔记。Paperpane 没有接收用户论文、笔记或密钥的自营服务器，也没有广告或使用分析追踪。

## 保存在浏览器里的数据

- 你打开或导入的论文及其来源地址、书目、阅读进度、批注、笔记、翻译和 AI 交互记录，以及你的文献库和设置，按功能保存在浏览器的扩展存储中。
- 为了识别网页和浏览器里的 PDF，扩展在本机检查标签页地址、网页里的链接和嵌入元素，以及部分请求的地址和 PDF 相关响应头。浏览器会话中的识别状态用于打开对应文件，随标签页关闭或浏览器会话结束而清除。扩展不会把浏览历史发送给 Paperpane。
- 你输入的模型或翻译 API 密钥、Zotero 密钥和 WebDAV 凭据保存在本机，仅在连接对应服务时用于认证。导出的 Paperpane 备份和 WebDAV 同步数据不包含这些凭据。

## 连接的服务

- **网页 PDF。** 当你打开网页上的 PDF 时，浏览器会向该论文站点或文件托管方请求文件。需要登录的文件可能使用该站点已有的浏览器会话。
- **模型和翻译。** 使用这些功能时，所选服务会收到该任务需要的文本、提问、对话上下文、图片或论文片段。概览和提前转写如果启用，打开论文后即可自动把相关内容发送到你配置的模型。使用免费谷歌翻译时，待翻译文本会发送给 Google。使用其他模型或翻译服务时，数据会发给你选择的服务商或自定义端点，按其隐私政策处理。远程模型端点需要 HTTPS，本机回环地址可以使用 HTTP。
- **WebDAV。** 开启同步或发起云备份后，选定的 WebDAV 服务会收到相应的文献库记录、笔记、批注、阅读成果及纳入同步或备份的文件。开启自动同步后，扩展会在后台定期同步。
- **Zotero。** 连接 Zotero 时，扩展向 Zotero API 提交认证信息以查询个人库。主动导入或导出时，扩展与 Zotero 交换你选择的记录、PDF、批注或笔记。导出附件时按你的配置使用 Zotero 文件存储或 WebDAV。
- **服务目录和版本信息。** 在设置中刷新模型目录或获取 OpenRouter 模型列表时，扩展会向 Models.dev 或 OpenRouter 请求公开目录。手动安装版可能向 GitHub 查询 Paperpane 的公开版本信息。这些请求不包含你的文献或 API 密钥。

Paperpane 仅为上述论文阅读功能处理数据，不出售用户数据，也不将其用于广告或信用评估。Paperpane 对来自 Google API 的信息的使用遵守 Chrome 网上应用店的用户数据政策及其 Limited Use 要求。该承诺同样适用于扩展处理的其他用户数据。

## 管理和删除

你可以在文献库删除条目并清空废纸篓，在设置中移除密钥、停用相关功能或断开连接。卸载扩展可移除浏览器为该安装保存的本地扩展数据。你导出的备份、WebDAV 上的文件及第三方保留的数据需要在相应位置或服务中单独删除。第三方服务对请求及记录的保留期限由其各自政策决定。

如有隐私问题，可通过 [Paperpane 项目](https://github.com/Robbings/Paperpane/issues) 联系维护者。公开问题中请勿附上凭据或私人论文内容。
